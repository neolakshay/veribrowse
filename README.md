# VeriBrowse

AI browser agent that tries to actually get things done.

Give it a goal.
It figures out what to do, uses the browser, and checks if it actually worked.

### What it does

- Understands the task
- Plans
- Browses
- Takes actions
- Verifies
- Saves checkpoints
- Recovers when things go wrong
- Asks before sensitive actions
